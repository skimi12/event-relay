# 実取引・収益化開始の確認事項

更新：2026-11-25 JST

公開プレビューと、実在する企業間取引を受け付ける運営開始は別の段階です。現時点では実在出品・売上・成約の実績はありません。

## 実取引前

- 実在する運営者名称、連絡窓口、必要な表示情報を確定する。
- 収集する情報と公開範囲、利用目的、保存期間、削除・開示手続を明示する。
- 当事者の売買と運営サービスの契約を区別し、成立時点、運搬責任、傷・欠品、取消と紛争時の扱いを規約とUIで一致させる。
- 古物営業等の要否を実際の関与形態に基づいて確認する。オークション・仕入販売・廃棄物回収を追加する際は再検討する。
- 出品者に所有権/譲渡権限、再利用可能な状態、実際の搬出許可を確認する。ログインだけを企業審査とみなさない。
- 下書き・写真・申込・連絡先のアカウント分離、二重予約防止、取消、期限切れを複数アカウントで検証する。
- 通報と対応担当、障害時の連絡、バックアップ/復元、不要データ削除を運用可能にする。

## 実課金前

- 手数料率・税込/税別・最低料金・発生条件・支払時期を公開する。
- 決済事業者のマーケットプレイス契約、本人/事業者確認、入金口座を本人が設定する。
- 金額をクライアントから信用せず、サーバー側の取引条件から確定する。
- 支払成功をブラウザーの戻りURLだけで判断せず、検証済みwebhookと台帳で管理する。
- 取消・返金・支払失敗・二重送信・部分失敗を検証する。
- 運営者の対応時間を含めた採算と、実際の買い手・売り手の支払意思を確認する。
